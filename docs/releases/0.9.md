# 手机控制与键鼠协同大更新

[项目首页](../../README.md) · [开发验收](../development.md)

当前实现：**macOS 0.9.6 / Android 0.9.6，协议 v1**。本页汇总 0.8–0.9 系列的功能变化，不代表新增 GitHub Release 或 1.0 发布。

## 从输入工具扩展到键鼠控制

新增可选 Android 辅助功能服务，用 Mac 鼠标移动手机指针、点击、长按、拖动和返回。控制中点到普通输入框后可直接输入中文，Mac 显示当前输入框内容，不必退出捕获再切回实时输入。控制期间手机常亮，Esc、失焦或手机暂停均可结束控制。

工作台和小窗统一为「实时输入 / 手机控制」两种模式，移除整段发送。纯文字输入仍不依赖辅助功能；多机同步保留在实时输入，控制和协同文字仅面向当前手机。

配套更新包括局域网自动发现与换网重连、小窗自动尝试连接、输入法面板点击进入 App。保留扫码配对、证书固定校验、设备认证、密码框保护和敏感信息不落日志。

## 升级

1. 两端更新到 0.9.6。安装包构建方式见[开发文档](../development.md)，无需清除原有配对。
2. 手机启用接收和输入法；需要控制时再启用「Remote Input 手机控制」。升级后系统未重新加载触控能力时，关闭再开启该服务。
3. Mac 连接已保存手机，进入手机控制并点击捕获。手机输入法未启用或不支持完整快照时，鼠标可用，但协同打字不可用。

无需新增 Mac 辅助功能权限，无 ADB、Root、USB 调试或云端依赖。当前不提供投屏、滚轮映射、多点触控或鸿蒙原生版本。

## 已修复的控制问题

- 重复成功响应不再重复启动捕获、导致立即退出。
- 指针显示使用帧插值；移动与拖动合并保留按下/松开顺序。
- 手机取消一次触摸后仍保持捕获，松开再按下恢复，不补发旧手势。
- 捕获确认后不再重新检查全局鼠标位置，避免多屏或等待期间位置变化误取消。
- 无输入框、密码框拒绝只暂停协同文字，不停止鼠标控制。

## 验证范围

Swift 43 项、Android 49 项测试通过，两端构建和 Android lint 已通过。当前电脑已实际验证连接小米、点击进入捕获、密码框拒绝时继续捕获以及 Esc 退出。中文组词、连续拖动、复杂 App 和不同手机的完整体验仍需按[验收清单](../development.md#实机验收清单)逐项实测，不能以单元测试或手势派发成功代替。

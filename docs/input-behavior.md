# 输入行为与多设备说明

[返回项目首页](../README.md)

## 设备名称与多手机

两端更新到 0.5.0 后，配对和重连会交换名称。0.6.2 起，Mac 优先使用系统电脑名称，若为纯编号则回退到 MacBook Pro 等硬件名称；手机优先读取系统设备名称，缺失时用可读机型或品牌名称。Mac 默认自动命名，并保留旧版已保存的手动名称；手机可在 App 中点「改名」或「自动命名」。名称在下次连接时同步，手机显示已配对电脑名称和连接状态；Mac 侧栏显示手机名称和连接状态。名称只是显示信息，认证仍依赖独立设备密钥和证书指纹。旧配对无需重新生成密钥，重连即可补全名称。

- **添加手机**：侧栏「我的手机」旁点 `+`，扫描另一台手机二维码；每台手机独立保存地址、名称和 Keychain 密钥。同一证书重新扫码会更新原记录，不产生重复设备。
- **切换输入**：点侧栏手机名称，保持其他连接在线，但输入只发给当前手机。切换会暂停并丢弃尚未发送的输入；点击输入区继续。已经交给网络的请求可能在原手机完成，绝不会转投新手机。
- **同步输入**：开启「多机同步输入」，勾选接收手机，点「连接勾选的手机」，在每台手机选中普通输入框后点击 Mac 输入区。文字、Enter、Backspace、方向键分别按顺序送往所有勾选手机。改变勾选项会暂停；重启应用默认关闭同步输入。
- 同步时顶部明确显示接收对象；点击手机名称只切换该手机的输入框预览，勾选项才决定接收者。预览仍来自对应手机的真实输入框，不能代表其他手机的内容。
- 任一目标断线、密码框拒绝、锁屏或其他输入失败时暂停整组，不自动重试、不静默跳过失败手机。群发并非原子操作，也不保证同一时刻到达：部分手机可能已接受上一条输入，请逐台检查后继续。不同手机的光标、内容和 Enter 动作可能不同。
- 「我的手机」列表的垃圾桶按钮仅移除对应手机记录及本机密钥，其他手机不受影响。Android「忘记电脑名称」仍只作用于这台手机。

## 输入与窗口

- **实时输入（默认）**：点击输入区后打字。拼音候选阶段只在 Mac 本地处理，确认后的中文才发送；英文、粘贴的文本也自动发送。**0.6.0 起只有一个实时输入框**：显示手机聚焦框的实际文字，直接在同一框中输入、选中替换、删除或移动光标。中文候选阶段不会被回传内容打断。单机编辑核对手机内容与光标后才应用；手机内容或焦点已变化时拒绝过时修改、暂停并重新同步，避免旧画面覆盖新内容。多机同步仍按各手机自己的光标发送，当前框只展示所选手机，不跨手机复制整篇内容或选区。
- **输入框同步与编辑（两端需 0.6.0+）**：输入页面可见且有键盘焦点时约每 250ms 刷新；连续输入期间也会定期重新读取。它是快照，可能有短暂延迟。密码框、锁屏、无输入框、读取失败时清除旧显示。仅接受应用提供的完整文本，最多 2048 个 UTF-16 单位；应用不支持或内容过长时明确提示，不用发送记录或截断片段替代。文字仅存在内存，经已配对的加密连接传输，不保存到文件或日志。应用不支持读取时无法镜像，只能继续向手机发送文字和结构化键，不伪造手机内容。
- **整段发送**：先编辑文字，再点击发送或按 ⌘Return；发送后保留草稿，避免把尚未编辑完的段落送出。
- Enter、Backspace、方向键与文字按顺序发送。中文组合输入期间，这些键先用于本地选词和编辑；Enter 默认执行目标输入框的动作，支持自定义 actionId 和发送动作。输入区「回车」选项可为当前手机保存“自动／发送／换行”；Shift+Enter 始终换行。发送模式请求应用执行发送，不模拟点击屏幕，也不保证应用确实发出消息。微信请在「我 → 设置 → 聊天」开启「回车键发送消息」（取决于版本是否提供此项）；若微信不响应标准输入法发送动作，仍需在手机点击发送。
- 按 Esc、切到其他窗口、打开扫码或切换小窗，会暂停实时输入并清空尚未发送的队列。恢复时点击输入框或「继续输入」；返回窗口且输入框仍持有焦点时恢复输入。恢复不再受上一条请求仍在途的条件阻塞。已经交给网络的请求可能完成，不会自动重试。
- 密码框、锁屏、无输入框或编辑器拒绝时暂停；先处理手机上的状态，再继续输入。输入过长或队列满时也暂停，内容不会自动补发。
- 点击 Mac 顶部状态栏的键盘／手机图标打开 **紧凑弹窗**；再次点击图标或点到外部会收起并暂停输入。工作台右上角「切换到状态栏」可隐藏工作台并打开弹窗，弹窗右上角「展开工作台」可返回完整界面。关闭工作台后仍可从状态栏打开；退出应用使用应用菜单中的「退出」或 ⌘Q。弹窗与工作台共用连接，扫码通过侧栏在工作台内切换，不使用弹窗。
- Mac 和 Android 自动跟随各自系统浅色／深色模式，不需要单独设置。

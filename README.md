## 本次大更新：手机控制与键鼠协同

从远程打字，扩展到用 Mac 键鼠操作手机。当前 Mac 版本为 **0.10.2**、Android 为 **0.10.1**，建议一起更新；这是功能上的大更新，尚未发布 1.0。

- **鼠标操作**：移动手机指针，左键点击、按住拖动或长按，右键返回。
- **直接打字**：点中手机普通输入框后，继续用 Mac 输入中文，无需退出捕获或切换页面；Mac 同步显示手机文字。
- **随时退出**：按 `Esc` 恢复 Mac 鼠标；切到其他 Mac 窗口也会停止控制。
- **控制时常亮**：控制期间手机保持亮屏，结束后恢复系统自动息屏。

手机控制需要在 Android 上额外开启辅助功能；只打字不需要。**当前没有投屏，请看着手机屏幕操作。**

```mermaid
flowchart LR
    A[点击捕获鼠标] --> B[看手机屏幕操作]
    B --> C[左键点中输入框]
    C --> D[直接用 Mac 输入中文]
    D --> B
    B --> E[Esc 退出捕获]
```

## 能做什么

| 功能 | 使用体验 |
| --- | --- |
| 中文实时输入 | 用熟悉的 Mac 输入法打字，选词确认后自动送到手机，不必每次点击发送。也支持英文、表情和粘贴文字。 |
| 看着手机内容编辑 | 实时输入框显示手机当前输入框的内容，可以继续输入、删除、选中替换或移动光标。需要手机应用支持读取输入框内容。 |
| 手机控制 | 开启可选辅助功能后，捕获 Mac 鼠标：左键点击／拖动、右键返回；点中输入框后直接打字，Esc 退出。 |
| 自选回车行为 | 为每台手机选择「自动」「发送」或「换行」；`Shift + Enter` 始终用于换行。 |
| 全局快捷键 | 默认 `⌥⌘I` 呼出小窗并聚焦输入区；工作台侧栏可修改或停用，重启后保留设置。 |
| 状态栏小窗 | 打开时自动尝试连接已选手机，也可点击小窗中的连接按钮重试；连接成功后点击输入区继续，需要时展开工作台。 |
| 扫码配对 | Mac 扫描手机展示的二维码，无需手动填写地址或配对码；配对后记住设备，方便下次连接。 |
| 换网自动找回 | 连接中断可在新局域网重新寻找已配对手机；认证成功后更新地址，输入仍保持暂停。 |
| 多台手机切换 | 在「我的手机」中保存多台设备，点击名称即可切换输入对象。 |
| 多机同步输入 | 勾选多台手机，将文字与按键发送到这些手机各自聚焦的输入框。 |
| 诊断日志 | 手机上查看、导出或清空最近的运行事件，方便排查连接与拖动问题，不记录输入内容。 |
| Mac 推送更新 | 调试阶段由已配对 Mac 推送新版 APK，在手机确认安装，无需反复传文件。 |
| 友好设备名称 | 自动获取设备名称，手机也可以改名，多台设备更容易区分。 |
| 输入状态提示 | 手机未选中输入框、锁屏或进入密码框时暂停，并提示处理原因。 |

这是一个**手机输入与键鼠控制工具**。默认专注文字输入；开启可选的手机辅助功能后，还可以返回、进入主页、选择并点击界面控件。支持鼠标映射触控，操作时请看手机上的指针；当前不提供手机投屏。

## 开始使用

### 1. 准备好两端应用

你需要一台运行 **macOS 13 或更新版本**的 Mac，以及一台运行 **Android 10 或更新版本**的手机。两端安装 WiFi Remote Input，并连接同一 Wi-Fi；首次扫码需要 Mac 摄像头。

可以从 [GitHub 发布页](https://github.com/maxjchuang/wifi-remote-input/releases) 下载打包好的应用。当前提供 **v0.10.2 预览版**：

| 平台 | 下载 | 要求 |
| --- | --- | --- |
| Mac | [下载 Mac 应用 ZIP](https://github.com/maxjchuang/wifi-remote-input/releases/download/v0.10.2/WiFiRemoteInput-0.10.2-macOS.zip) | Apple Silicon（M 系列芯片），macOS 13+；应用版本 0.10.2 |
| Android | [下载 Android APK](https://github.com/maxjchuang/wifi-remote-input/releases/download/v0.10.2/WiFiRemoteInput-0.10.1-debug.apk) | Android 10+；应用版本 0.10.1 |
| 文件校验 | [SHA256SUMS.txt](https://github.com/maxjchuang/wifi-remote-input/releases/download/v0.10.2/SHA256SUMS.txt) | 校验下载文件是否完整 |

Mac 下载后解压，将 `WiFi Remote Input.app` 拖入「应用程序」；更新时先退出正在运行的旧版。Android 下载后在手机确认安装，再按下方步骤启用输入法并配对。手机不需要开启开发者模式、USB 调试，也不需要 Root。

这是开发预览包：Mac 使用本地临时签名，尚未经过 Apple 公证，系统可能阻止首次打开；Android 使用调试签名，覆盖安装要求原应用签名相同。Intel Mac 请参考[源码构建步骤](docs/development.md)。下载前请查看[发布说明与已知问题](https://github.com/maxjchuang/wifi-remote-input/releases/tag/v0.10.2)。

已在 MacBook Pro 与小米 13 / HyperOS 上验证基本输入和扫码配对，Android 新界面也已通过用户实机验收。其他机型与应用的表现可能有所不同。

### 2. 在手机上开启接收

打开手机 App，按页面提示完成「启用输入法」和「选择输入法」，然后点击「开启接收」。首次使用按系统提示允许通知，以便接收服务在后台运行。

输入法就绪后，点击「显示配对二维码」。

### 3. 用 Mac 扫码

在 Mac 客户端点击「扫码配对」，允许摄像头访问，将手机上的二维码对准 Mac 摄像头。识别成功后完成配对和连接。

二维码两分钟内有效，只能使用一次；收起后也会失效。过期时重新生成即可。

```mermaid
flowchart LR
    A[手机开启接收] --> B[手机展示二维码]
    B --> C[Mac 扫码连接]
    C --> D[手机点选输入框]
    D --> E[在 Mac 上打字]
```

### 4. 开始打字

在手机打开备忘录或聊天应用，点选一个普通输入框。回到 Mac，点击实时输入区，输入：

> 你好，小米 13 👋

中文选词确认后，文字会自动抵达手机。需要操作手机界面时，切换到「手机控制」。

之后使用时，在手机开启接收，在 Mac 选择已保存的手机并连接即可。Mac 会在局域网寻找已配对手机的新地址。已发起过连接的手机因换网断开时可自动重连，恢复后需点击输入区继续；手动断开则不会自动重连。应用重启后仍需点击连接。自动发现被网络阻止时，可以重新扫码更新地址。

## 用鼠标控制手机

### 首次开启

1. 在手机 App 的「手机控制」卡片点击「开启辅助功能」，在系统设置中启用 **Remote Input 手机控制**。保持手机解锁。
2. 在 Mac 连接手机，选择「手机控制」，点击中央控制区。
3. 出现“鼠标捕获中”后，Mac 鼠标暂时隐藏，手机出现黑底白边的箭头指针和浮动暂停标记。第一次点击只开始捕获，不会点击手机内容。
4. 看着手机屏幕移动、点击或拖动。退出时按 `Esc`；小窗会同时收起。中文组词时，`Esc` 先交给输入法取消组词。

更新 APK 后若触控不可用，可在手机系统设置中关闭再开启该辅助功能。手机输入法面板的标题、说明和留白也可点击，直接返回 App；「切换输入法」按钮仍打开系统选择器。

| 想做什么 | 操作 |
| --- | --- |
| 移动手机指针 | 移动 Mac 鼠标 |
| 点击 | 左键按下并松开 |
| 拖动、滑动页面 | 按住左键移动，松开结束 |
| 长按 | 按住左键不动 |
| 返回上一页 | 右键；拖动时先松开左键 |
| 输入中文、英文或表情 | 点中手机普通输入框，等待 Mac 显示同步内容后直接打字 |
| 调整回车行为 | 捕获前选择「自动／发送／换行」；中文确认后 `Shift + Enter` 换行 |
| 主页、最近任务 | 控制区下方按钮；先退出捕获再点击 |
| 停止控制 | `Esc`、切换 Mac 窗口，或在手机触摸浮动暂停标记 |

### 打字与鼠标可以连续使用

点中手机输入框后，Mac 控制区会显示该框的文字。中文候选在 Mac 本地显示，选词确认后送达。点击其他位置或右键返回时，会清除未确认的组词，重新检查手机输入框。

没有输入框或进入密码框时，只暂停文字，鼠标仍可操作。应用无法提供完整输入框内容时，**键鼠协同中的打字不可用**，可退出捕获并切换「实时输入」尝试普通文字提交。

控制只作用于当前选中的手机，**即使开启多机同步，也不会向其他手机广播鼠标或协同文字**。退出控制、断线超时或停止接收后释放常亮要求；不会更改系统息屏时间，也不会唤醒或解锁手机。

### 目前的边界

没有投屏、滚轮映射或多点触控。坐标点击不要求应用支持键盘焦点，但系统和应用仍可能拒绝或取消手势；游戏、自绘界面等不能保证兼容。拖动被取消时，松开左键再按下重试，不必退出整个捕获。

没有可编辑输入框时，还可用方向键、Tab / Shift+Tab 选择可访问控件，Enter 点击、Shift+Enter 长按、Page Up / Down 滚动。这些辅助操作取决于目标应用的支持；普通输入框已同步时，方向键和 Enter 优先用于文字编辑。

## 多台手机怎么用

- **添加**：点击 Mac「我的手机」旁的 `+`，扫描另一台手机的二维码。
- **切换**：点击列表中的手机名称，再点击输入区继续。其他手机的连接可以保持在线。
- **同步输入**：开启「多机同步输入」，勾选接收手机并连接，在每台手机上点选输入框，然后在 Mac 输入。
- **忘记设备**：点击手机列表中对应的删除按钮。手机端也可以忘记已配对电脑。

同步输入会发到每台手机自己的光标位置，**不会让多台手机的整篇内容自动保持一致**。输入区预览只对应当前选中的手机。任一手机无法接收时会暂停整组；部分手机可能已经收到上一条输入，继续前请逐台检查。

目前一台 Mac 可以连接多台手机，但每台手机只保留一台已配对 Mac。重新配对另一台 Mac，会使原电脑的配对失效。

## 诊断日志与调试更新

手机首页点击「诊断日志与更新」，可以查看最近的连接、认证、控制和错误事件。复现问题后点击「导出日志…」，选择保存位置；也可以关闭记录或清空日志。最多保留 300 条，不记录输入内容、剪贴板、鼠标轨迹、设备名称、地址、配对码和密钥，会通过加密连接自动同步到已配对 Mac，不上传公网。

从 **0.10.1** 起，手机日志会在连接空闲时随每 5 秒心跳自动同步，忙碌时延后。Mac 自动保存到 `/tmp/wifi-remote-input/phone-<设备标识>.log`，点击侧栏「查看手机日志」可打开当前设备文件，Codex 也可直接读取该目录分析。每台手机覆盖保存最近 300 条，重连后会补同步当前快照；断线期间不实时传输，超过 300 条的旧事件不会补回。关闭手机日志记录后停止传输事件，下次同步清空对应 Mac 快照。`/tmp` 是临时目录，系统可能清理，需要长期保存时请另行复制。

调试阶段通过 Mac 推送新版，暂不接入 GitHub Releases：

1. **首次手动安装 Android 0.10.0 或更新版本**，并更新 Mac 客户端。旧手机版本尚不具备接收更新能力。
2. 手机开启接收，与 Mac 连接；在「诊断日志与更新」点击「允许接收更新（10 分钟）」。
3. Mac 选中目标手机，点击侧栏「推送手机更新…」，选择新版 APK。推送期间暂停该手机的输入和控制。
4. 手机提示新版就绪后，点击「安装已收到的更新」，按系统提示确认。首次可能需要允许此应用安装未知来源应用，再返回点击安装。

只接受相同应用、相同签名、**版本号更高**的 APK；同版本和旧版本不会覆盖安装。推送中断后重新允许接收并重试，不会自动补传或静默安装。完成安装后重新打开手机 App，检查接收和辅助功能状态。开发者构建规则见[开发文档](docs/development.md)。

## 隐私与输入保护

- **仅在本地网络传输**：连接经过加密与设备认证，不经过云端中转，未配对的电脑不能输入。
- **密码框禁止远程输入**：锁屏时也会拒绝输入。密码识别依赖手机应用正确标记输入框类型。
- **不保存输入历史**：用于同步显示的文字只在内存中处理，不写入文件或日志；配对码和密钥也不会写入日志。
- **键盘只作用于当前输入区**：切到其他 Mac 窗口后暂停，避免影响其他软件。纯文字输入无需授予手机辅助功能权限。
- **断线不自动补发**：避免重复文字或误发消息；检查手机状态后再继续。

Mac 会使用系统钥匙串保存配对凭据，用于下次识别设备，不用于存储你输入的文字。

## 常见问题

### 手机提示「没有聚焦的输入框」怎么办？

先在手机打开目标应用，点击要输入的位置，并确认当前选中 WiFi Remote Input 输入法。再回到 Mac 点击输入区继续；仅连接手机并不代表手机已经准备好接收文字。

### 为什么微信按 Enter 没有发送？

可以先将 Mac 的回车模式切换为「发送」。若微信版本提供「回车键发送消息」，请在微信「我 → 设置 → 聊天」中开启它。不同应用对回车的处理不同；若应用不响应输入法的发送动作，可以在「手机控制」中用鼠标点击手机的发送按钮。

### 为什么电脑上没有显示手机的完整文字？

部分手机应用不允许输入法读取完整内容，过长的内容也不会显示。此时客户端会提示同步不可用。「实时输入」仍可尝试提交文字和按键；「手机控制」中的协同打字需要有效快照，不会用发送历史冒充手机内容。详细限制见[输入行为说明](docs/input-behavior.md)。

### 扫码后无法连接，或切换手机应用后断开？

检查两端是否在同一 Wi-Fi、手机是否开启接收。访客网络可能禁止设备互连或阻止自动发现；先确保两端在同一个可互通的网络。自动发现不可用时可重新扫码，扫码不能绕过网络隔离。HyperOS 若限制后台运行，请在系统电池设置中允许 App 后台运行，并保留接收服务的通知。

### 怎么打开小窗、暂停或退出？

点击 Mac 顶部状态栏图标，或按 `⌥⌘I` 呼出小窗并聚焦输入区，右上角可展开工作台。工作台侧栏「呼出小窗」可设置包含 `⌘` 或 `⌃` 的字母／数字组合，按 `Esc` 取消录入；无法注册时会提示更换，并保留原快捷键。应用需保持运行，退出后快捷键不生效。小窗中按 `Esc` 会暂停输入并收起窗口；中文候选阶段优先取消选词。切到其他窗口也会暂停实时输入。手机点击「暂停接收」停止接收；Mac 使用 `⌘ Q` 退出应用。
